# بستهٔ ادامهٔ مرحلهٔ ۹ — محیط Preview

تاریخ پایه: ۲۰۲۶-۱۰-۱۳؛ ترتیب Policy/E2E در ۲۰۲۶-۱۰-۲۰ اصلاح شد. بستهٔ پایه روی شاخهٔ `ops/preview-readiness-phase9a-20261013` ثبت شده است. [گزارش ۹A](../docs/preview-readiness-phase9a-fa.md) بررسی فقط‌خواندنی و اصلاح مانع آزمون پس از تولید محتوا را ثبت می‌کند؛ این سند مجوز Deploy، ایجاد محیط پولی، Migration یا تغییر تنظیمات نیست.

کار این نوبت، اصلاح Runtime یا تغییر رنگ/طراحی نیست. بدون عکس/متن مالک می‌توان ورودی‌ها و جدایی محیط را آماده کرد؛ پذیرش ظاهر، کیفیت عکس و زمان بارگذاری واقعی به محتوای نهایی و مراحل ۱۰ تا ۱۲ نیاز دارد. هیچ درصد سرعت یا امتیاز آمادگی از شمار آزمون‌ها ساخته نمی‌شود.

## حدود شواهد

- یک پروژه و یک Branch پیش‌فرض در اتصال Supabase دیده شد؛ دربارهٔ محیطی خارج از Scope این اتصال نتیجه‌گیری نشده است.
- ابزار GitHub موجود APIهای Secret/Administration را ارائه نمی‌کند. وجود مقادیر، دسترسی واقعی Cloudflare و مجوز انتشار از وضعیت CI استنتاج نشده‌اند؛ محدودیت با CLI یا Browser دور زده نشد.
- خطای قبلی Preview محلی `uv_interface_addresses` باقی است؛ این نوبت تلاش اجرا یا تعویض میزبان برای دورزدن آن انجام نشد. نتیجهٔ مرورگر هنوز «انجام‌نشده» است.
- [SQL حداقلی](../scripts/preview-readiness-audit.sql) فقط در پروژهٔ صریحاً انتخاب‌شده، READ ONLY اجرا می‌شود. شمار RLS یا Version برابر، ممیزی همهٔ مجوزها/رفتار را جایگزین نمی‌کند.
- طبق [AGENTS.md](../AGENTS.md): «هیچ Deploy یا تغییر Production، DNS، دامنه، Search Console یا انتشار عمومی بدون اجازهٔ صریح مالک انجام نمی‌شود.» آماده‌سازی و بررسی‌های مجاز تا رسیدن به این اقدام مشخص ادامه‌پذیرند.
