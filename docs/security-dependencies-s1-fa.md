# S1 — اصلاح وابستگی‌های آسیب‌پذیر

تاریخ: ۲۰۲۶-۱۰-۰۸. مبنا: `c04c3034d23c77b3e6e74d918da69f7d85485f08`، شامل مرحلهٔ ۵ و برنامهٔ تکمیل. این تحویل روی شاخهٔ `security/dependency-hardening-20261008` است؛ ادغام یا انتشار انجام نمی‌دهد.

## مشکل و نتیجه

Lockfile مبنا ۴۲ تطبیق Advisory برای ۱۰ نام بسته داشت: ۲ Critical، ۲۲ High، ۱۲ Moderate و ۶ Low، با ۳۸ Advisory یکتا. حضور یک Advisory به معنی اثبات حملهٔ موفق به سایت نیست. دو مسیر مهم، Seroval مصرف‌شده در Server Functionها و Sharp مصرف‌شده در تولید رسانه بودند.

در نسخهٔ اصلاح‌شده، `bun audit --json` خروجی `{}` و exit 0 دارد. این نتیجه مربوط به Lockfile و پایگاه Advisory در تاریخ بررسی است؛ تضمین نبود همهٔ آسیب‌پذیری‌ها یا تأیید امنیت کل محیط نیست.

| بسته              | نسخهٔ مبنا                     | نسخهٔ اصلاح‌شده     |
| ----------------- | ------------------------------ | ------------------- |
| `seroval`         | `1.5.6`                        | `1.6.8`             |
| `sharp`           | `0.34.5`                       | `0.35.5`            |
| `brace-expansion` | `1.1.16` و `5.0.8`             | `1.1.21` و `5.0.12` |
| `esbuild`         | `0.27.3`                       | `0.28.2`            |
| `js-yaml`         | `4.3.0`                        | `4.3.2`             |

| `source-map-js`   | `1.2.1`                        | `1.2.2`             |
| `undici`          | `7.24.8`                       | `7.30.0`            |
| `ws`              | `8.20.1` و نسخهٔ سالم `8.21.1` | هر دو `8.22.0`      |

Sharp اکنون وابستگی مستقیمِ دقیقِ Build در `devDependencies` است؛ Generator دیگر به موجودبودن اتفاقی آن از Miniflare وابسته نیست. پنج Override دقیق برای Seroval، Sharp، Undici، ws و esbuild، نسخه‌های قدیمیِ پین‌شده یا چندمسیره را کنترل می‌کنند. سایر اصلاحات داخل بازهٔ سازگار والد و در Lockfile ثبت شده‌اند؛ دو نسل brace-expansion جدا حفظ شده‌اند.

نسخه‌های React، TanStack، Vite، Nitro، Lovable و Wranglerِ مبنا حفظ شده‌اند. ارتقای گستردهٔ فریم‌ورک یا انتقال شبیه‌ساز به Miniflare 5 بخشی از این اصلاح نیست. Lockfile سایر بسته‌ها از مبنا حفظ و فقط ورودی‌های موردنیاز اصلاح امنیت و بسته‌های بومی Sharp/esbuild جایگزین شدند. نصب مستقل و `--frozen-lockfile` سازگاری Lockfile را تأیید کردند.

## آزمون رفتار

- یک Fixture محلی با طول ۸، به‌جای تخصیص بزرگ، منبع اشتباه TypedArray را بازتولید می‌کند. نسخهٔ مبنا در JSON و Cross JSON آن را می‌پذیرفت؛ نسخهٔ اصلاح‌شده با علت `SerovalMalformedNodeError` رد می‌کند. این آزمون هیچ Endpoint زنده‌ای را فراخوانی نمی‌کند.
- دادهٔ شبیه درخواست با متن فارسی/انگلیسی و TypedArray معتبر در هر دو مسیر Seroval Round-trip می‌شود.
- آزمون Native با عکس مصنوعی فقط در Test، JPEG، PNG، WebP و AVIF را Decode می‌کند؛ جهت EXIF، خروجی ۳۲۰/۶۴۰/۱۲۸۰، سقف‌های ۳۰/۷۰/۲۲۰KiB برای هر قالب، و حذف Metadata بررسی می‌شوند. MIME ناسازگار، SVG، JPEG خراب و تصویر کوچک رد می‌شوند؛ بودجهٔ ناممکن هم شکست کنترل‌شده دارد.
- توابع رسانهٔ واقعی Generator برای آزمون قابل Import شده‌اند. Import، Credential نمی‌خواند و Artifact را پاک نمی‌کند؛ اجرای مستقیم CLI با Fetch ساختگیِ کاملاً آفلاین در پوشهٔ موقت آزموده شد و Artifact خالیِ معتبر ساخت.
- هیچ عکس مصنوعی، دادهٔ مشتری یا محتوای ساختگی به سایت یا دیتابیس اضافه نشده است.

در CI یک Gate به نام `security:audit` اضافه شده است؛ هر Advisory گزارش‌شده باعث شکست آن می‌شود. اجرای dry-run در CI ارسال Metrics و Error Reports را خاموش می‌کند. نتیجهٔ CI هر Head باید در همان PR بررسی شود؛ این جدول نتیجهٔ محلی است.

## اثر بر حجم

اندازه‌گیری از Buildهای تولیدیِ مبنا و نسخهٔ اصلاح‌شده با محتوای یکسان و gzip سطح ۹ انجام شد. Graph کامل اولیهٔ صفحهٔ اول، نه فقط Entry، شمارش شده است. دادهٔ ماشین‌خوان در [security-s1-bundle-summary-20261008.json](security-s1-bundle-summary-20261008.json) است.

| معیار                  | مبنا، بایت     | اصلاح‌شده، بایت |
| ---------------------- | -------------- | --------------- |
| JavaScript اولیهٔ خام  | ۴۴۲٬۰۳۵        | ۴۴۶٬۷۹۹         |
| JavaScript اولیهٔ gzip | ۱۳۶٬۹۳۳        | ۱۳۷٬۹۴۴         |
| CSS خام / gzip         | ۲۶٬۲۷۶ / ۶٬۲۴۸ | ۲۶٬۲۷۶ / ۶٬۲۴۸  |
| فونت محلی خام          | ۱۳۰٬۹۷۲        | ۱۳۰٬۹۷۲         |

هزینهٔ وصله‌ها ۱۰۱۱ بایت gzip در JavaScript اولیه است. این تغییر حجم است؛ افت یا افزایش سرعت واقعی، LCP، INP، CLS و رتبهٔ سئو از آن قابل اثبات نیستند. کتابخانهٔ انیمیشن تازه اضافه نشده است.

## محدودیت و ادامه

Overrideهای Sharp و esbuild از پین دقیق والد ابزار ساخت عبور می‌کنند؛ آزمون Native و ساخت/بسته‌بندی سازگاری مسیرهای بررسی‌شده را نشان می‌دهند. شبیه‌ساز، مرورگر، CSP/Turnstile و سه مسیر ثبت درخواست همچنان به پذیرش واقعی Preview روی همین Head نیاز دارند. بعد از ارتقای والدها، Overrideهای غیرضروری باید با Audit و Gate کامل حذف شوند؛ حذف بی‌بررسی مجاز نیست.

این تحویل به RLS، Secret، Edge زنده، Postgres، ضداسپم، Rate Limit، بکاپ، DNS یا Production دست نمی‌زند. بسته‌های S2 و S3 پیش از مرحلهٔ ۶ باقی‌اند: کاهش Log خصوصی، Headerهای مشترک، سقف خواندن Build و قرارداد URL؛ سپس جداسازی Preview، وصلهٔ Postgres و بکاپ/Restore قابل اتکا. `rate_limit_policy.enabled` طبق قرارداد تا E2E موفق Preview خاموش می‌ماند.
