# ۱۲B — آمادگی جست‌وجوی فهرست‌ها و مقصد درست تعویض زبان

تاریخ: ۲۰۲۶-۱۰-۱۳ به وقت تهران. مبنا: PR64، Commit `da8ff6ae3d2ce86f1949a341df8ec68197d84393`.

خانه و فهرست‌های مزار، راهنما و نمونه‌کار از وجود مسیر انگلیسی، آمادگی ترجمه برای جست‌وجو را نتیجه می‌گرفتند. کلید زبان نیز می‌توانست کاربر را به جزئیات ترجمه‌نشده ببرد. این بسته قواعد آمادگی را با Sitemap هماهنگ می‌کند و «ترجمهٔ قابل خواندن» را از «صفحهٔ قابل ایندکس» جدا نگه می‌دارد.

نتیجهٔ Fixture را به رفتار مرورگر، رتبهٔ گوگل یا مقصد واقعی تعمیم نمی‌دهیم.

## مرز داده و هزینه

- همان هشت Adapter و همان RPC موجود `getSite` استفاده می‌شوند. فراخوانی پیش‌فرض همچنان `Site|null` است؛ Root با پرچم Boolean معتبر، Envelope شامل `site` و فقط جدول کوچک آمادگی را می‌گیرد. هیچ Endpoint، Package، Route یا درخواست محتوا به زبان دیگر اضافه نشده است.
- Root همچنان فقط `getSite` و `getPage("not-found")` را فراخوانی می‌کند. محتوای سایر زبان‌ها در کلاینت بارگیری نمی‌شود؛ Flagها فقط `fa/en` هستند و Body، عکس، SEO کامل یا اطلاعات تماس ندارند.
- سیاست سرور از Artifact پاک‌سازی‌شدهٔ همان Build ساخته می‌شود، یک‌بار در هر Worker isolate محاسبه و در هر خروجی Clone می‌شود؛ تغییر Clone به دادهٔ مشترک سرایت نمی‌کند. دادهٔ Build در یک Deployment ثابت فرض می‌شود؛ تغییر منبع به Build جدید نیاز دارد.
- واکشی محتوای زیرصفحه با انتظار نتیجهٔ Parent به‌صورت موازی آغاز می‌شود. دو فهرست راهنما/نمونه‌کار اکنون مدل `{items,indexableLocales}` و `{cards,indexableLocales}` دارند؛ View و آزمون Loader واقعی مطابق آن اصلاح شده‌اند.
- پالت، قاب‌ها، سه خدمت هم‌وزن، حرکت، عکس و کپی کسب‌وکار، Package/Lockfile، Workflow، Edge و تنظیمات مقصد تغییری ندارند. Label بومی زبان داخل `span lang` قرار گرفت تا توضیح فارسی/انگلیسی لینک با زبان جاری خوانده شود.

تست حذف/Skip نشد. انتظار قدیمیِ سه Alternate برای خانهٔ بدون هویت و Index برای فهرست فاقد جزئیات آماده اصلاح شد؛ آزمون مثبتِ SSR واقعی از حذف اشتباه صفحات آماده جلوگیری می‌کند. Source guardهای `await adapter` با واکشی موازی سازگار شدند؛ آزمون واقعی تعداد/Locale فراخوانی Adapterها حفظ شد.

## وضعیت پذیرش و ادامه

۱۲B یک بستهٔ کد مرحلهٔ ۱۲ است. پنج مرحلهٔ اصلی ۹ تا ۱۳ هنوز بازند. [Snapshot آمادگی](seo-locale-navigation-readiness-20261013.json) این تمایز را ثبت می‌کند.

1. مرحلهٔ ۹: Preview/Access مستقل و Scope/Origin واقعی، بکاپ رمزنگاری‌شده و Receiver/Restore واقعی طبق بستهٔ پیشین؛ Snapshot محیط این نوبت تجدید نشد.
2. مرحلهٔ ۱۰: عکس، هویت، خدمات، محصول و متن حقوقی بازبینی‌شدهٔ واقعی در هر دو زبان؛ محتوای غایب جعل نمی‌شود.
3. ادامهٔ مرحلهٔ ۱۲: بازبینی پاسخ HTTP/404 و متادیتای اجتماعی/ساختاریافته بدون ادعای ساختگی، سپس پذیرش Sitemap/Head/Header/Crawlability روی مقصد واقعی؛ اینها از Fixture در حافظه اثبات نمی‌شوند.
4. مرحلهٔ ۱۱ و عملکرد ۱۲: مرورگر واقعی، Keyboard/Reflow/Zoom/Screen reader، عکس‌های نهایی و Baseline/CWV ثابت.
5. مرحلهٔ ۱۳: پذیرش نسخه، Rollback و مجوز صریح Merge/Deploy/انتشار.

در این بسته Merge، Deploy، تغییر DB/Schema/Policy/Secret/Cloudflare/Storage، ورود عکس واقعی یا پیام به دیگران انجام نشده است.

- [Supabase Changelog](https://supabase.com/changelog): HTML خوانده شد؛ نسخهٔ Markdown قابل خواندن نبود. هیچ وضعیت TLS/DB/Auth واقعی از اطلاعیه نتیجه‌گیری نشد؛ این بسته فقط Artifact عمومی را مصرف می‌کند.
