# ۱۲A — نقشهٔ سایت و متادیتای جست‌وجوی دوزبانه

تاریخ: ۲۰۲۶-۱۰-۱۳ به وقت تهران. مبنا: PR63، Commit `410f33032a3736bff9af40b75e7c077189e0fe11`.

این بسته آماده‌سازی مستقل کدِ سئوی فنی مرحلهٔ ۱۲ است. پذیرش مرحلهٔ ۹، ورود محتوای مرحلهٔ ۱۰، آزمون مرورگر مرحلهٔ ۱۱ و اندازه‌گیری واقعی مرحلهٔ ۱۲ همچنان بازند. پالت، ظاهر، حرکت، وزن سه خدمت، Package/Lockfile، Workflow، Edge، DB و تنظیمات مقصد تغییر نکردند.

## قواعد پیاده‌سازی

- Sitemap همچنان Handler سرور دارد. فقط با GET، مسیر `/sitemap.xml`، `PUBLIC_INDEXING=true` و HTTPS Origin تمیزِ `SITE_URL` ساخته می‌شود؛ میزبان/Query درخواست وارد URL عمومی نمی‌شوند. Preview غیرفعال 404، Origin نامعتبر/خطای محتوا/انتشار کاملاً خالی 503 با No-store می‌دهد. پاسخ مثبت XML همان Cache قبلی را دارد.
- Root هر زبان به هویت برند در رکورد همان زبان نیاز دارد؛ نام واقعی غایب جعل نمی‌شود. فهرست مزار و راهنما به دست‌کم یک جزئیات قابل ایندکس، و پرتفولیو به کارت عمومی قابل نمایش نیاز دارند.
- About/Contact/Privacy/Terms/Building/Stoneworks از صفحهٔ Git همان زبان، Body قابل نمایش و SEO خودارجاع بررسی می‌شوند. Stoneworks به دسته‌های صریح مصوب نیاز دارد. Home Git/Not-found، فرم درخواست و URL داخلی در فهرست صفحات محتوایی قرار ندارند.
- پیشوند/مسیر ثابت از قرارداد دوزبانه می‌آید؛ آزمون کامل تطابق، افزودن مسیر تازه بدون تصمیم Eligibility را آشکار می‌کند.
- محصول فعالِ فاقد Variant قابل نمایش، Slug خراب یا `custom` که با مسیر ثابت برخورد دارد، Slug/Locale مبهم، Canonical نامتجانس و Robots منفی حذف می‌شود. راهنمای تکراری، بدون عنوان/Body یا Canonical صحیح نیز حذف می‌شود. برچسب غایبِ محصول قدیمی فارسی می‌ماند؛ برچسب نامعتبر Fallback نمی‌شود. صفحات Git برچسب صریح لازم دارند.
- Noindex به معنی حذف متن قابل خواندن نیست. صفحهٔ ترجمه‌شده می‌تواند قابل مطالعه و Noindex باشد، ولی همتای جست‌وجویی معرفی نمی‌شود. `noindex,nofollow` و `none` مالک حفظ می‌شوند؛ محافظ آمادگی آنها را به Follow شل نمی‌کند.
- Canonical جزئیات از Slug مدل و Canonical صفحات از مسیر واقعی همان Route ساخته می‌شود. Hreflang هر مجموعهٔ موجود دوطرفه، شامل خودش و فقط همتای معتبر است. `x-default` تنها وقتی فارسی همان صفحه معتبر است درج می‌شود؛ برای مقاله/محصول فقط انگلیسی، صفحهٔ فارسی ساختگی معرفی نمی‌شود.
- `translationLocales` اکنون در DTO محصول/صفحه/راهنما نشانگر **همتای جست‌وجوی قابل ایندکس** است و فقط توسط Repository مشتق می‌شود؛ فیلد نگارش منبع یا وضعیت تمام ترجمه‌های خواندنی نیست. نام هشت Adapter عوض نشده و سرور/API تازه‌ای اضافه نشده است.
- Sitemap فقط Origin+مسیر و تاریخ معتبر راهنما را منتشر می‌کند؛ Title/Body/تماس، شناسهٔ خصوصی رسانه، اطلاعات فرم یا Token وارد XML نمی‌شوند. XML Entity escaping، URLهای کوتاه‌تر از ۲۰۴۸ نویسه، حذف تکرار و ترتیب پایدار حفظ شده‌اند. تاریخ Build، Priority یا Changefreq ساخته نمی‌شود.
- Projection خنثی فارسی برای تماس انگلیسی، در Sitemap هویت انگلیسی محسوب نمی‌شود و رکورد دوم فارسی هم نمی‌سازد؛ نبود EN Site دیگر Root فارسی را به اشتباه مبهم نمی‌کند.

انتخاب Noindex برای دو فرم درخواست، شرط هویت برای Root و Eligibility محافظه‌کارانه، تصمیم این پروژه‌اند؛ حکم اجباری گوگل برای تمام سایت‌ها نیستند.

## هزینهٔ حجم

دو Build نهایی با همان محتوای خالیِ مصوب، Gzip سطح ۹ و Mtime صفر مقایسه شدند. Graph اولیه با `Bun.Transpiler.scan` نسخهٔ نصب‌شدهٔ 1.3.14، Entry و تمام Importهای ثابت پیمایش شد؛ Routeهای Dynamic در Graph اولیه وارد نشدند.

هر ۲۳ فایل عمومی JS/CSS/WOFF2 در [مقایسهٔ حجم/SHA](seo-locale-indexing-bundle-20261013.json) ثبت است. CSS و دو فونت از نظر نام/بایت/Gzip/SHA برابرند. تغییر Hash نام Chunkهای JS ناشی از متادیتا و ارجاع به Entry تازه است؛ Chunk/کتابخانهٔ حرکت یا درخواست بیرونی تازه اضافه نشد. کد ساخت Sitemap روی سرور می‌ماند.

این دادهٔ **حجم کد** است؛ زمان دریافت/Render/CPU سرور، LCP/INP/CLS، سرعت شبکه و درصد افزایش/افت سرعت از آن ثابت نشده‌اند. ورودی بدون عکس نهایی و بدون دادهٔ عملیاتی واقعی است.

## کارهای باز بعد از ۱۲A

1. **۱۲B، کد:** سرصفحهٔ Home/Grave list/Portfolio/Guide list با همان آمادگی Sitemap هماهنگ شود؛ برخی همچنان Hreflang هر دو زبان را از وجود Route فرض می‌کنند. پوشش دیتای کاملاً خالی، تنها یک زبان و همهٔ جزئیات Noindex لازم است.
2. **۱۲B، ناوبری زبان:** Language switch نمایشی در جزئیات/صفحهٔ غایب بررسی شود. نشانگر SEO را جای موجودبودن ترجمهٔ خواندنی استفاده نکنیم؛ رفتار Noindex با متن موجود و ترجمهٔ واقعاً غایب متفاوت است.
3. **مرحلهٔ ۹:** Preview/Access مستقل، Scope/Origin/Secret واقعی و بکاپ/Receiver/Restore طبق Gateهای قبلی. این نوبت DB/Cloudflare/Storage خوانده یا تغییر داده نشد.
4. **مراحل ۱۰/۱۱/۱۲:** محتوای مالک، حقوقی و ترجمهٔ واقعی؛ سپس HTTP/404/SSR/Headers/Indexing، Crawlability/Canonical/Hreflang، لینک داخلی، عکس، مرورگر و Baseline/CWV.
5. **مرحلهٔ ۱۳:** نسخهٔ دقیق، Rollback و مجوز صریح Merge/Deploy/انتشار.

پنج مرحلهٔ اصلی ۹ تا ۱۳ همچنان بازند. این بسته SEO را تمام‌شده، محیط را پذیرفته یا سایت را آمادهٔ انتشار نمی‌کند. [Snapshot آمادگی](seo-locale-indexing-readiness-20261013.json) تفاوت آمادگی کد و پذیرش را ثبت می‌کند.

## منابع رسمیِ خوانده‌شده

- [Google — ساخت Sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap): URL کامل و Canonical ترجیحی، تاریخ آخرین تغییر معنی‌دار و محدودیت Sitemap. منبع توصیه‌هاست، نه شاهد رتبهٔ دامنهٔ ما.
- [Google — نسخه‌های زبان](https://developers.google.com/search/docs/specialty/international/localized-versions): مجموعهٔ خودارجاع/دوطرفه و URL کامل؛ HTML/HTTP/XML روش‌های معادل‌اند. Hreflang در HTML نگه داشته شد و نسخهٔ موازی XML اضافه نشد.
- [Google — Noindex](https://developers.google.com/search/docs/crawling-indexing/block-indexing): Meta/HTTP و نیاز به مشاهدهٔ آن توسط Crawler. کنترل دسترسی Preview از Noindex جداست؛ HTTP مقصد این نوبت آزموده نشد.
- [Sitemaps protocol](https://www.sitemaps.org/protocol.html): UTF-8، Namespace، Entity escaping، طول URL و W3C Datetime؛ تاریخ Generation جای Lastmod نیست.
- [TanStack — Server Functions](https://tanstack.com/start/latest/docs/framework/react/guide/server-functions): مرز Server/Stub و Validator؛ نسخهٔ نصب‌شده و اجرای واقعی نیز شاهد پروژه‌اند.
- [Bun — Transpiler](https://bun.com/docs/runtime/transpiler): Scan و تفاوت Import ثابت/Dynamic؛ API در نسخهٔ ثابت نصب‌شده آزموده شد، Runtime ارتقا نیافت.
- [Supabase Changelog](https://supabase.com/changelog): Markdown به علت Content-type ابزار خوانده نشد و صفحهٔ HTML خوانده شد. اعلان TLS پیشین به وضعیت کلاینت واقعی تعمیم داده نشد؛ این بسته فقط Repository کامپایل‌شده را تغییر می‌دهد و هیچ API/DB/Policy زنده را تغییر نمی‌دهد.

اصول منبع، تصمیم پروژه، اجرای Fixture و پذیرش واقعی چهار نوع شاهد متفاوت‌اند. پژوهش تازهٔ پالت یا همهٔ رقبای جهان در این نوبت انجام نشده است.
