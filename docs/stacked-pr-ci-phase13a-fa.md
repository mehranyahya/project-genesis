# آماده‌سازی مستقل ۱۳A: بررسی خودکار پیش‌نویس‌های وابسته

تاریخ: ۲۰۲۶-۱۰-۱۴. پایهٔ کد `77ea61c4fa44e961fc6c9fd1135d64fbc8f2d828`، شاخهٔ `ci/stacked-pr-verification-20261014`.

## مشکل و تغییر

در بررسی فقط‌خواندنی GitHub، PR45 تا PR73 همگی باز و Draft بودند؛ ۲۹ پیش‌نویس وابسته با پایه/Head متوالی و بدون مغایرت زنجیره. main همان `73868949c34e581af636e8ef2d4fc36fb3c42321` بود. با این حال، `.github/workflows/ci.yml` رویداد `pull_request` را به مقصد `main` محدود می‌کرد؛ در همین Snapshot، PR46 تا PR73 از این شرط عبور نمی‌کردند. CI تاریخیِ یک Head، اجرای خودکار بعد از تغییر همان پیش‌نویس را ثابت نمی‌کند.

فقط فیلتر `branches: [main]` از `pull_request` حذف شد. بازشدن، به‌روزرسانی Head و بازگشایی پیش‌نویس با مقصد شاخهٔ مرحلهٔ قبل نیز از مسیر عادی PR بررسی می‌شوند. فیلتر Push به main، Jobها، Action SHAها، نسخهٔ ابزارها و `permissions: contents: read` دقیقاً حفظ شدند. `pull_request_target` یا انتشار/دسترسی تازه اضافه نشد. بازشدن این پیش‌نویس روی شاخهٔ PR73 باید اجرای خودکار را بدون تغییر موقت مقصد به main نشان دهد؛ شاهد واقعی Run جدا ثبت می‌شود.

مبنای رفتار فیلتر/رویداد: [GitHub workflow syntax](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax) و [pull_request events](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#pull_request)، خوانده‌شده در تاریخ همین گزارش. رفع فیلتر، اجرای گذشتهٔ PRهای قبلی را بازسازی نمی‌کند؛ نسخهٔ قدیمی Workflow روی شاخهٔ قدیمی خودبه‌خود به‌روزرسانی نمی‌شود.

## بررسی‌های انجام‌شده

- YAML با BaseLoader خوانده شد تا `on` به Boolean تبدیل نشود؛ ساختار Trigger، ثابت‌ماندن Push، برابری تمام Jobها/Permissions و نبود رویداد تازه بررسی شدند.
- دادهٔ واقعی ۲۹ PR با شرط قبلی تطبیق داده شد: ۲۸ مقصد غیرmain حذف می‌شدند؛ با فیلتر جدید همه واجد شرایط PR هستند.
- نصب Frozen با Bun 1.3.14، Content check، TypeScript و هر دو Edge check موفق‌اند.
- تست‌های موجود: ۹۹۹ Pass، صفر Fail، ۱۰۱ فایل. تست جدیدی که صرفاً حذف یک خط YAML را تکرار کند نوشته نشد.
- Lint: صفر Error و ۲۹ Warning موجود. اجرای نخست با تستی که پوشهٔ موقت ایجاد/حذف می‌کرد تداخل داشت؛ پس از پایان تست‌ها، Lint به‌تنهایی موفق شد. نقص برنامه یا Pass صوری ثبت نشد.
- Audit: صفر Advisory شناخته‌شده؛ Build و Artifact preflight موفق‌اند.
- Native recovery: نه سناریو با age v1.3.2 و بایت/کلید کاملاً آزمایشی موفق‌اند؛ Archive با SHA256 پین‌شدهٔ Workflow بررسی شد. این نتیجه بکاپ/Restore واقعی نیست.
- Dry-run سختگیرانهٔ Wrangler 4.97.0 روی Artifact تولیدشده موفق است؛ هیچ Upload/Deploy یا Browser/HTTP سایت انجام نشده است.
- تغییر Runtime، CSS، فونت، تصاویر، وابستگی/Lockfile، Schema یا درخواست نداریم؛ سنجش واقعی سرعت/CWV نیز از این بررسی نتیجه نمی‌شود.

## حدود و ادامه

موجودی کامل محلی پیش از این بسته، ۳۱ Commit و ۳۲۷ فایل متفاوت با main داشت. شمار جمعی Diffهای مرحله‌ای ۵۷۰ است و به دلیل تغییر چندبارهٔ بعضی فایل‌ها، شمار فایل یکتای نهایی نیست. این ممیزیِ وابستگی/موجودی، بازبینی محتوای تک‌تک خط‌ها یا پذیرش کامل انتشار نیست. PR44 خارج از این زنجیره و Head آن خارج از Candidate است؛ بستهٔ آن خودکار ادغام یا بسته نمی‌شود.
