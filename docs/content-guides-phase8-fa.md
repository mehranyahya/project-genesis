# مرحلهٔ ۸ — منبع و اتصال راهنماها

تاریخ: ۲۰۲۶-۱۰-۱۳، تهران. مبنا `0f331257acfac03477d8fbe3b4f948ee5eaa849b`، [Draft ۶۱](https://github.com/mehranyahya/project-genesis/pull/61)، شاخهٔ `content/guides-phase8-20261013`.

قالب راهنما پیش‌تر موجود بود اما `getGuides`/`getGuide` همواره خالی/null می‌دادند. اکنون مقالهٔ بازبینی‌شدهٔ Git از Build به Repository و همان Adapterهای رسمی، فهرست، جزئیات و بخش راهنمای صفحهٔ اول می‌رسد. تاریخ نسخهٔ انگلیسی و اقدام پایانی مقاله ترجمه می‌شوند. **مرحلهٔ ۸ از نظر کد آمادهٔ ورود محتواست؛ پنج مرحلهٔ اصلی ۹ تا ۱۳ باقی است.** این پایان پذیرش محتوای واقعی، S3، Preview، سرعت یا انتشار نیست.

## قرارداد و رفتار

| مسیر       | رفتار قابل بررسی                                                                                                                                                                                                      |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

صداقت تاریخ و اطلاعات، صحت ترجمه، اعتبار منبع و مرتبط‌بودن مقصد لینک را مالک/ویراستار بررسی می‌کند؛ اعتبارسنجی قالب، آن واقعیت‌ها را اثبات نمی‌کند. جزئیات کامل در [قرارداد راهنماها](../content/guides/README.md) است. مقاله اختیاری است؛ نبودش به‌تنهایی انتشار سه خدمت را مسدود نمی‌کند و Gateهای حقوقی/ساختاری همچنان ضروری‌اند.

| بررسی            | نتیجهٔ نهایی محلی                                                                                                                                                                                         |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| آزمون کامل       | **۹۵۰ pass، صفر fail، ۸۸ فایل؛ ۲۰ آزمون بیشتر از مبنای ۷B**                                                                                                                                               |

| بررسی‌های کد     | Lint صفر خطا و ۲۹ هشدار قبلی؛ TypeScript، Edge check، Content check و Audit موفق، صفر آسیب‌پذیری گزارش‌شده در زمان آزمون.                                                                                 |
| Build و Artifact | دو Build تازه با Dependency قفل‌شده؛ آماده‌سازی/اعتبارسنجی Artifact و strict dry-run محلی موفق، بدون Upload/Deploy.                                                                                       |
| Readiness        | [خروجی محلی](content-guides-readiness-20261013.json): **۲۴ required blocked، دو deferred، دو pass**؛ `readyForPublication=false`. اتصال اختیاری راهنما Pass شد؛ مقالهٔ واقعی هر زبان همچنان Deferred است. |
| Release content  | exit 1 مورد انتظار، به‌علت نبود متن قانونی/ساختاری واقعی؛ موفقیت Code check مجوز انتشار نیست.                                                                                                             |

اجرای اولیهٔ متمرکز ۵۵ pass/دو fail و یک خطای TypeScript نشان داد: Fixture مسیر مقاله را به‌جای `$slug` ثابت ساخته بود؛ آزمون مستقیم Function منبع نیز Context/Transform TanStack نداشت. این دو محیط آزمون و Locale صریح DTO اصلاح شدند. اجرای نخست کل مجموعه ۹۴۹ pass/یک fail بود؛ آزمون قدیمی SSR خانه هم اکنون باید همان Transport را در فرایند جدا اجرا کند. Loader/Adapter/Repository/View واقعی و تمام Assertionهای قبلی حفظ و H1/غیبت Guide تقویت شدند؛ سپس ۹۵۰/۰ موفق شد. Test حذف/Skip یا Gate ضعیف نشده است. اجرای اولیهٔ Audit به‌علت PATH اجرایی Bun شروع نشد؛ اجرای مستقیم همان Bun، صفر آسیب‌پذیری داد.

Transport در Fixture جدا جای RPC/Context شبکه را می‌گیرد؛ این آزمون HTTP مرورگر، Retry/Error واقعی شبکه یا مقصد Preview نیست. خروجی CI باید به Head همین بسته مربوط باشد؛ نتیجهٔ نهایی در GitHub و گزارش کامل ثبت می‌شود. نه سناریوی اجباری Native Age/Recovery در CI حفظ شده‌اند؛ Native Age محلی این نوبت اجرا نشد.

## هزینهٔ حجم

[جزئیات نام/اندازه/SHA](content-guides-bundle-20261013.json)، دو Build با Dependency و محتوای خالی یکسان:

| مجموع فایل‌های عمومی |           مبنا |     پیشنهادی |     تغییر |
| -------------------- | -------------: | -----------: | --------: |
| JS، تعداد            |             ۲۰ |           ۲۰ |       صفر |
| JS، خام              |        ۵۳۴٬۶۱۲ |      ۵۳۵٬۵۳۳ | +۹۲۱ بایت |
| JS، مجموع gzip       |        ۱۶۸٬۱۸۸ |      ۱۶۸٬۵۵۹ | +۳۷۱ بایت |
| CSS، خام/gzip        | ۲۶٬۲۷۶ / ۶٬۲۴۸ | دقیقاً برابر |       صفر |
| دو WOFF2، خام        |        ۱۳۰٬۹۷۲ | دقیقاً برابر |       صفر |

نام/اندازه/SHA تمام CSS و دو فونت برابرند. gzip با Python level 9 و mtime صفر، مجموع تمام JS عمومی است؛ دانلود اولیه، CDN Transfer، درصد افت سرعت یا CWV نیست. اندازهٔ واقعی Summary/Article و عکس و زمان تعامل با محتوای نهایی/شبکه در مرحلهٔ ۱۲ سنجیده می‌شوند. کنترل اندازهٔ فایل منبع جای بودجهٔ دادهٔ واقعی را نمی‌گیرد. در اسکن اولیهٔ حجم، فونت‌های خارج `assets` شمرده نشده بودند؛ اسکن نهایی کل `.output/public` هر دو WOFF2 و برابری واقعی‌شان را تأیید کرد.

Package/Lockfile، پالت، تعداد Route و Adapter، قرارداد Media/قیمت/Terms/درخواست، Workflow انتشار، Schema و DB تغییر نکردند. هیچ مقاله/عکس/محتوای برند فرضی متعهد نشده است. Migration، Query زنده، تغییر Secret/Policy، Merge، Deploy یا پیام به دیگری انجام نشد.

مرحلهٔ بعد **۹، بررسی آمادگی محیط Preview و مسیر تولید محتوا** است؛ در محدودهٔ فقط‌خواندنی و Gateهای قبلی. محتوا، پذیرش ظاهر/درخواست/دسترس‌پذیری، سرعت/SEO و انتشار مراحل ۱۰ تا ۱۳ و S3 واقعی بازند. بستهٔ عکس همچنان هشت منبع صفحهٔ اول و نه عکس پیشنهادی سه مدل آغاز است؛ راهنما انتخابی است و الزام عکس تازه ایجاد نمی‌کند.

منبع رسمی بررسی‌شده در ۱۳ اکتبر: [TanStack Start — Server Functions](https://tanstack.com/start/latest/docs/framework/react/guide/server-functions)، دربارهٔ مرز GET/Validator و کد Server. سقف منبع/تعداد، Summary کوچک، Version مشترک و ترتیب مقاله‌ها تصمیم مهندسی این پروژه‌اند؛ شواهد رفتار از کد و Fixture همین نسخه است، نه اثبات برتری طراحی جهانی.
