# مرحلهٔ ۶C — ورود ترجمهٔ ساختاری و خطای نهایی دوزبانه

تاریخ: ۲۰۲۶-۱۰-۱۳، تهران. مبنا: `fad80aaa2b6716d7f841a1997f3da4ac3ed0af34`، [Draft ۵۸](https://github.com/mehranyahya/project-genesis/pull/58). شاخهٔ مستقل: `content/structured-translations-phase6c-20261013`.

پیش از این، Generator فقط محتوای فارسی منتشر می‌کرد و Site انتخاب زبان نداشت؛ خطای نهایی Worker هم در مسیر انگلیسی فارسی بود. اکنون متن بازبینی‌شدهٔ انگلیسی در Build روی محتوای عملیاتی موجود قرار می‌گیرد؛ متن مبدأ تغییرکرده، ترجمهٔ ناقص یا تأییدنشده خروجی انگلیسی معتبر نمی‌سازد. خطای نهایی نیز زبان و لینک خانهٔ همان مسیر را دارد.

**زیرساخت کد مرحلهٔ ۶ پس از ۶A/۶B/۶C آماده است؛ متن واقعی، پذیرش S3 و Preview یا انتشار آماده نیستند.** تغییر دیتابیس برای این قرارداد لازم نشد. هفت مرحلهٔ اصلی ۷ تا ۱۳ باقی‌اند؛ این شمار تعداد نوبت‌ها نیست و پیش‌نیازهای واقعی محیط/بکاپ را حذف نمی‌کند. متن حقوقی واقعی در ورود محتوا و E2E در پذیرش محیط/رابط همچنان بازند.

## قرارداد منبع و ثبات عملیات

- [منبع ترجمه و روش تهیهٔ مرجع](../content/translations/README.md): فارسی از Supabase موجود می‌آید؛ متن انگلیسی تأییدشده در `content/translations/en.json` نسخه‌دار است. هشت نام Adapter حفظ و `getSite(locale)` به ServerFn معتبر وصل شد.
- Root شامل schemaVersion/locale/revision/status/reviewed و Map محصول/نمونه‌کار/Site است. فقط published+reviewed با Revision معتبر وارد Artifact می‌شود؛ Draft یا فایل غایب هیچ رکورد انگلیسی منتشر نمی‌کند. زبان/نسخه/کلید ناشناخته، Duplicate JSON key واقعی، UTF-8 بد، لینک فایل، سقف ۸MiB و عمق زیاد رد می‌شوند؛ خطا مقدار ورودی را چاپ نمی‌کند.
- ترجمهٔ محصول فقط عنوان، خلاصه/شرح، SEO، alt، شامل/غیرشامل و عنوان Option را عوض می‌کند. Product/Variant/Option ID، Slug، Code، نوع محصول، Stone/Size، مبلغ، نوع/زمان قیمت، موجودی و کاتالوگ از منبع عملیاتی فعلی حفظ می‌شوند؛ ترتیب از آن منبع می‌آید.
- تمام Variant/Option/رسانهٔ هر محصول ترجمه‌شده باید پوشش داشته باشد و شمار شامل/غیرشامل برابر باشد. ID ناشناخته، غیرفعال یا مبهم، URL/قیمت/شناسهٔ اضافه، متن فارسی در فیلد انگلیسی و Canonical زبان اشتباه Build را متوقف می‌کنند. انتخاب زیرمجموعهٔ محصول/نمونه‌کار مجاز است؛ سایر موارد انگلیسی غایب‌اند.
- رسانهٔ ترجمه فقط alt برای Asset ID عمومی همان عکس است؛ هیچ عکس/URL/ابعاد تازه یا خصوصی از ترجمه منتشر نمی‌شود. عکس اصلی، تأیید privacy/consent و خروجی Native قبلی پیش‌نیاز باقی‌اند.
- Source Hash متن مبدأ، مالکیت، Variant/Option، هویت تصویر واقعی و alt را پوشش می‌دهد. تغییر متن/عکس/رابطه حتی با Hash عملیاتی برابر، ترجمهٔ قدیمی را مسدود می‌کند. قیمت، موجودی و زمان قیمت خارج این Hashاند؛ تغییر آن‌ها ترجمهٔ همان متن را نیازمند بازبینی بی‌دلیل نمی‌کند و DTO مبلغ/موجودی تازه را می‌گیرد.
- Hash، بررسی نوع و منع نشت فارسی، اثبات دقت زبانی/معنایی نیستند؛ تأیید انسانی ترجمه و صحت خدمات/عکس همچنان لازم است. Source Hash نیز Snapshot تراکنشی چند درخواست DB نیست؛ محدودیت پیمایش ۶A باقی است.
- Site متن نام/نشانی/ساعت را از همان زبان می‌خواند؛ شماره، لینک‌ها و نام لاتین همان دادهٔ خنثی موجودند. در غیبت ترجمه، نشانی/ساعت فارسی وارد انگلیسی نمی‌شوند؛ نمایش نام لاتین و تماس خنثی مطابق قرارداد قبلی حفظ شد. Repository کپی مستقل برمی‌گرداند.

## مرجع نگارش و حفظ خروجی قبلی

`structured:generate --translation-source <new-path>` با Build هدف مجاز، مرجع Draft از محتوای واقعی عمومی می‌سازد. Destination موجود بازنویسی نمی‌شود. این حالت Artifact و عکس عمومی را عوض نمی‌کند؛ هزینهٔ خواندن/اعتبارسنجی رسانه در Build دارد. قیمت، Secret، Storage key و Consent reference در مرجع نیستند. هیچ مرجع واقعی این نوبت تولید نشد؛ CLI فقط با دادهٔ مصنوعی اجرا شد.

یک نقص قابل مشاهدهٔ Generator هم اصلاح شد: قبلاً قبل از خواندن/اعتبارسنجی، پوشهٔ رسانه حذف می‌شد؛ در شکست Artifact قدیمی می‌ماند اما عکسش ممکن بود غایب باشد. اکنون کل رسانه/DTO در پوشهٔ موقت خارج public آماده می‌شوند؛ شکست ترجمه/خواندن خروجی قبلی را حفظ می‌کند. نصب موفق رسانهٔ قدیمی بی‌مرجع را از public کنار می‌گذارد. خطای نصب Artifact، رسانهٔ قبلی را بازمی‌گرداند؛ اگر خود بازگردانی شکست بخورد Backup موقت نگه داشته می‌شود و خطای Recovery می‌دهد. پوشهٔ نگهداری از Git خارج است.

**محدودیت صریح:** چند Rename فایل/پوشه تراکنش مقاوم به قطع فرایند/خاموشی نیستند؛ توقف میان نصب ممکن است به بازیابی دستی از Stage نیاز داشته باشد. این ابزار Build، بکاپ ماندگار یا Restore واقعی Production نیست و Gateهای S3 را نمی‌بندد.

## خطای نهایی

دو مسیر Throw و JSON خطای بلعیده‌شدهٔ H3 در Worker، زبان را از قرارداد URL می‌گیرند. `/en` و `/en/...` انگلیسی‌اند؛ `/enough` انگلیسی فرض نمی‌شود. HTML ثابت، scriptless، no-store و با CSP قبلی است؛ Query/پیام خطا در خروجی نمی‌آید. لینک خانه `/en` یا `/` است، حداقل ارتفاع کنترل ۴۸px و Focus حفظ شد. HTML خطای عادی از سمت Framework بی‌دلیل بازنویسی نمی‌شود. هیچ کتابخانهٔ Runtime، انیمیشن، فونت یا Theme جدید اضافه نشد.

Fixture واقعی CLI با PNG مصنوعی، ابتدا مرجع Draft ساخت و خروجی قبلی را دست‌نخورده نگه داشت؛ سپس متن انگلیسی reviewed را وارد کرد و دو DTO با شناسه/قیمت/عکس مشترک ساخت. تغییر متن مبدأ با نسخهٔ کاتالوگ برابر و حذف Option ترجمه، ساخت را متوقف و Artifact/فهرست رسانهٔ قبلی را حفظ کردند. هیچ Fixture/عکس/متن ساختگی وارد Artifact متعهدشدهٔ سایت نشد.

آزمون واقعی filesystem نصب موفق، شکست نصب فایل یا رسانه، بازگردانی بایت قبلی و رد Symlink را بررسی کرد. Fixture فرایند جدا Repository/Adapter/Factoryهای واقعی را برای Site دو زبان، چهار فرم و Contact، سپس غیبت ترجمه اجرا کرد؛ تماس/نام لاتین خنثی ماندند و نشانی/ساعت فارسی حذف شدند. Fixture Worker، هر دو نوع Fatal و مرز مسیر زبان و عدم نشت Query/خطا را با HTTP مصنوعی اجرا کرد. این‌ها Browser یا E2E محیط واقعی نیستند.

تست‌ها حذف یا Skip نشدند؛ Assertionهای قبلی انتخاب Site به Locale صریح تغییر و حفاظت‌های قدیمی حفظ شدند. فرمان CLI تازهٔ چندساختی به مهلت ۴۵ ثانیه محدود است؛ اجرا حدود شش ثانیه است و Timeout شبکه/Child همچنان محدود ماند. گام اجباری نه سناریوی واقعی Age/Recovery در CI حفظ شد؛ نتیجهٔ CI باید متعلق به Head همین بسته باشد.

## ادامه و مرز

زیرساخت مرحلهٔ ۶ از نظر کد آمادهٔ ورود محتواست. قدم بعدی مرحلهٔ ۷، اتصال متن/رسانهٔ خدمات و اصلاح Metadata مزارمحور باقی‌مانده است؛ سپس راهنما، Preview، محتوای واقعی، پذیرش رابط/فرم، عملکرد/SEO و انتشار. مصرف اختصاصی SEO محصول در Head، Sitemap و اندازه‌گیری واقعی طبق مرحلهٔ سئو بررسی می‌شوند؛ ترجمهٔ فیلد در Artifact به‌تنهایی آن بررسی‌ها را انجام‌شده نمی‌کند.

این نوبت Query زندهٔ Supabase، Migration، تغییر Secret/Policy، تصویر واقعی، ثبت درخواست واقعی، پیام، Merge یا Deploy اجرا نشد. Preview مستقل، Receiver/کپی ماندگار/Decrypt/Restore، Postgres/ACL و مجوز انتشار همچنان بازند. Rate Limit DB خاموش و Guard بکاپ پابرجاست؛ محدودیت قبلی Preview/مرورگر با ابزار جایگزین دور زده نشد.

## منابع جاری بررسی‌شده

[Supabase Changelog](https://supabase.com/changelog) در ۱۳ اکتبر خوانده شد؛ `.md` نوع محتوای قابل دریافت نداشت و HTML استفاده شد. اطلاعیهٔ ۱۲ اکتبر حذف برخی Cipherهای قدیمی CBC در HTTP API، زودترین زمان ۱۰ نوامبر، مشاهده شد. کتابخانهٔ TLS/SDK یا DB تغییر نکرد و استفاده/عدم استفادهٔ مقصد واقعی از این Cipherها ادعا نمی‌شود؛ بررسی محیط باقی است. راهنمای رسمی [local database reset](https://supabase.com/docs/reference/cli/supabase-db-reset) از SearchDocs خوانده شد؛ Reset/Migration لازم نشد و اجرا نشد. انتخاب Git برای متن، تصمیم طراحی این پروژه است و دستور Supabase برای محل ترجمه نیست.
