# مرحلهٔ ۷B — رسانهٔ خدمات و انتخاب ثابت عکس

تاریخ: ۲۰۲۶-۱۰-۱۳، تهران. مبنا `71bcfa019e52f82b85bac2383b2f41b2921b61fd`، [Draft ۶۰](https://github.com/mehranyahya/project-genesis/pull/60)، شاخهٔ `design/service-media-phase7b-20261013`.

رسانهٔ ساختمانی پیش‌تر پردازش می‌شد اما در خروجی مصرف‌شدهٔ صفحات قرار نمی‌گرفت. اکنون رسانهٔ تأییدشدهٔ ساختمانی در Artifact عمومی هر زبان قرار می‌گیرد و صفحات خدمات، عکس ساختمانی یا پروژهٔ همان زبان را با انتخاب صریح و ثابت به View می‌رسانند. نمونهٔ سنگ، شناسهٔ پروژه یا قیمت فرضی نمی‌گیرد؛ پروژهٔ واقعی ارجاع خود را تا فرم حفظ می‌کند.

**کد مرحلهٔ ۷ پس از ۷A/۷B آمادهٔ ورود محتواست؛ شش مرحلهٔ اصلی ۸ تا ۱۳ باقی است.** این پایان پذیرش عکس/متن واقعی، S3، Preview یا انتشار نیست. عدد مرحله تعداد نوبت‌ها یا درصد پیشرفت محسوب نمی‌شود.

## مسیر محتوا

| مرحله             | قرارداد قابل بررسی                                                                                                                                                                                                                |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| منبع خصوصی        | همان جدول‌های موجود رسانه، بدون Migration؛ فقط رسانهٔ ساختمانی فعال با `privacy_cleared=true` و مدرک رضایت خصوصی غیرخالی قابل انتشار است.                                                                                         |
| Encode            | مسیر موجود Magic/MIME/Decode/ابعاد، WebP/AVIF در ۳۲۰/۶۴۰/۱۲۸۰ و سقف بایت/حذف Metadata حفظ شده است. Source یا Storage key به خروجی عمومی نمی‌رود.                                                                                  |
| Artifact ساختمانی | `GENERATED_BUILDING_MEDIA` به تفکیک زبان، تنها با پنج فیلد `src,srcSet,width,height,alt`؛ Item ID، رضایت، کلید خصوصی و Source Hash در آن نیستند.                                                                                  |
| ترجمه             | فیلد اختیاری `buildingMedia` در قرارداد موجود نسخهٔ ۱، با Asset ID و Source Hash عکس/alt مبدأ. متن انگلیسی بازبینی‌شده، بدون Override مسیر/ابعاد، همان عکس را با alt همان زبان منتشر می‌کند. نبود ترجمه هیچ fallback فارسی ندارد. |
| انتخاب صفحه       | `mediaReferences` اختیاری در صفحهٔ بازبینی‌شدهٔ `building-stone`/`stoneworks`، با حداکثر سه عکس، ترتیب صریح و Asset ID ثابت. `building` فقط ساختمانی است؛ `portfolio` به پروژهٔ عمومی منتشرشده اشاره می‌کند.                      |
| پاسخ Adapter      | `getPage` انتخاب را در Server از Artifact همان زبان حل و Selector را از پاسخ حذف می‌کند. تنها Media منتخب و در صورت پروژه‌بودن، Ref عمومی آن به مرورگر می‌رود. همان هشت Adapter و شکل پنج‌فیلدی Media حفظ شدند.                   |
| انتخاب ناقص       | عکس حذف‌شده/تغییرکرده، ترجمهٔ غایب، منبع نامعتبر/تکراری، SrcSet نادرست یا Ref مبهم، کل بخش تصویری را حذف می‌کند؛ جایگزین ضمنی از اولین عکس ساخته نمی‌شود.                                                                         |
| View              | قاب خنثی با contain و نسبت ثابت، ابعاد صریح، AVIF/WebP موجود، lazy و priority خودکار؛ بدون Carousel، گرادیان، انیمیشن یا کتابخانهٔ تازه.                                                                                          |
| درخواست پروژه     | Query فقط `source=portfolio` و Ref عمومی معتبر است و Locale حفظ می‌شود. Loader فرم وجود Ref در پرتفولیو همان زبان را دوباره بررسی می‌کند؛ نبود ترجمه، Ref معتبر انگلیسی نمی‌سازد.                                                 |

جابه‌جایی ترتیب گالری، Asset انتخاب‌شده را تغییر نمی‌دهد. انتخاب هیچ عکس، کل کاتالوگ عکس را به مرورگر نمی‌فرستد. حداکثر سه عکس به این بخش معرفی خدمت مربوط است؛ گالری محصول یا صفحهٔ کامل پرتفولیو محدود نشده‌اند. عکس ساختمانی به فرم موجود همان خدمت متکی است و اطلاعات نوع/ابعاد/قیمت محصول فرضی نمی‌سازد. نقش واقعی عکس در خدمت، کیفیت رگه/پرداخت و مجوز مالک در مرحلهٔ ۱۰ پذیرفته می‌شوند؛ انتخاب دستی شناسه، آن تأیید معنایی را ثابت نمی‌کند.

## شواهد آزمون

Fixture CLI با PNG مصنوعی واقعی، رسانهٔ ساختمانی را از Queryهای آفلاین خواند، Encode کرد، مرجع Draft با Source Hash داد و Media پنج‌فیلدی دو زبان با مسیر یکسان ساخت. رضایت غایب، حریم خصوصی تأییدنشده و تغییر alt ساختمانی، ساخت را متوقف و Artifact/رسانهٔ قبلی را حفظ کردند. ترجمهٔ ناقص محصول و متن مبدأ تازه نیز همچنان رد شدند. هیچ متن/عکس مصنوعی وارد Artifact متعهدشدهٔ سایت نشده است؛ baseline عمومی همچنان خالی است.

Fixture جدا، Parser، Repository، Adapter، Factory، Router حافظه و View واقعی دو خدمت را با SSR دو زبان اجرا کرد: یک عکس منتخب، یک H1، ابعاد، AVIF/WebP، lazy/priority خودکار و contain. لینک پروژه با Locale و Ref تا Loader واقعی فرم بررسی شد؛ حذف ترجمه عکس و Ref معتبر انگلیسی را غایب کرد. تغییر Media خروجی خواندن قبلی، Artifact خواندن بعدی را تغییر نداد. آزمون انتخاب، ترتیب متفاوت گالری، عکس حذف‌شده، انتخاب نیمه‌کامل، SrcSet/ابعاد/URL نامعتبر و نشت alt فارسی را جدا پوشش داد.

آزمون قبلیِ «صفحهٔ ساخت سفارشی بدون تصویر» با قرارداد رسانهٔ مصوب به‌روز شد: Page فقط رسانهٔ حل‌شده از Adapter را مصرف می‌کند و Source/URL مستقیم، تصویر یا Offering ساختگی ندارد. تست‌های امنیت، قیمت، ثبت درخواست، Terms، Context خصوصی، Referral و هشت Adapter حذف یا Skip نشدند. CI باید متعلق به Head همین بسته باشد؛ نتیجهٔ نهایی آن در GitHub و گزارش کامل ثبت می‌شود. نه سناریوی اجباری Native Age/Recovery در CI حفظ شده‌اند؛ رمزنگاری واقعی محلی این نوبت اجرا نشد.

نام/اندازه/SHA تمام CSS و فونت‌ها برابرند. Chunk مشترک در Viewهای lazy دو خدمت مصرف می‌شود؛ انیمیشن، کتابخانه یا سرویس فونت تازه نداریم. gzip با Python level 9 و mtime صفر، مجموع تمام فایل‌هاست؛ دانلود اولیه، Transfer واقعی CDN، درصد افت سرعت یا CWV نیست. مقدار دادهٔ SSR و عکس با محتوای واقعی و شبکه در مرحلهٔ ۱۲ سنجیده می‌شود. عکس‌های انتخاب‌نشده در این بخش Render/Download نمی‌شوند؛ Browser با عکس واقعی هنوز آزموده نشده است.

## ادامه و مرز

مرحلهٔ بعد **۸، منبع و اتصال راهنماها** است. محتوای مقاله اختیاری باقی می‌ماند؛ راهنمای ساختگی تولید نمی‌شود. Preview، ورود محتوای واقعی، پذیرش رابط/درخواست، عملکرد/SEO و انتشار طبق مراحل ۹ تا ۱۳ و Gateهای مستقل S3 ادامه دارند. بستهٔ محتوا هنوز همان هشت منبع صفحهٔ اول و نه عکس پیشنهادی سه مدل آغاز است؛ این آماده‌سازی عکس اضافی اجباری نمی‌کند.

Query زنده، Migration، Secret/Policy/Workflow انتشار، عکس واقعی، درخواست واقعی، پیام، Merge و Deploy در این نوبت انجام نشد. محدودیت پیشین Preview/مرورگر با میزبان/ابزار جایگزین دور زده نشد. بکاپ/Checksum/Restore و Rate Limit DB خاموش پابرجایند. مراحل ۶/۷ از نظر کد آماده‌اند؛ متن حقوقی، درستی ترجمه، رضایت واقعی عکس و پذیرش محیط/سرعت/ظاهر هنوز بازند.

منابع رسمی در ۱۳ اکتبر: [Storage access control](https://supabase.com/docs/guides/storage/security/access-control)، [Changelog](https://supabase.com/changelog) و [اطلاعیهٔ CBC/TLS](https://supabase.com/changelog/cbc-tls-ciphers-deprecated). `.md` نوع محتوای قابل دریافت نداشت و HTML خوانده شد. اطلاعیهٔ HTTP API به وضعیت واقعی کلاینت/مقصد تعمیم داده نشد؛ TLS یا ACL زنده تغییر نکرد. انتخاب حداکثر سه عکس و حذف بخش ناقص، تصمیم طراحی/مهندسی پروژه است؛ شواهد رفتار از کد و Fixture همین نسخه‌اند، نه ادعای برتری طراحی جهانی.
